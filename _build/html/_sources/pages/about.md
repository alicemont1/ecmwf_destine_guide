# ECMWF's Destination Earth User Guide

This guide provides an overview of how to access and use the data and software products made available by ECMWF as part of the Destination Earth project.

It is not a full user manual for all services and datasets. Rather, it serves as a central reference point, offering concise descriptions and direct links to the official documentation for each service.
