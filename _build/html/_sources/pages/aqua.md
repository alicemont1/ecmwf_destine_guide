

# Monitoring and Evaluation Framework: AQUA

## About

AQUA is an open-source Python tool for real-time evaluation and uncertainty analysis of Climate DT simulations, developed by CNR and Politecnico di Torino.

It is integrated into the operational workflow of the Climate Adaptation Digital Twin, running on EuroHPC systems.
