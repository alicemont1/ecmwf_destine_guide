# How to Extract Data with Polytope
This section provides a brief overview of how to request data using Polytope.

The recommended method for extracting data from Polytope is via the [`earthkit-data`](https://github.com/ecmwf/earthkit-data) Python library, maintained by ECMWF.  
It is included as part of the [`earthkit`](https://github.com/ecmwf/earthkit) meta-package and simplifies both authentication and request syntax.

Under the hood, `earthkit-data` uses the lower-level `polytope-client` library to interact with the Polytope service.

For more advanced use cases or fine-grained control, you can use the [`polytope-client`](https://github.com/ecmwf/polytope-client) package directly.


:::{hint}
A comprehensive collection of Polytope examples is available in the [polytope-examples](https://github.com/destination-earth-digital-twins/polytope-examples) repository. 
:::


# Polytope Server Addresses for DestinE
To retrieve data from the EuroHPC infrastructure, users currently need to know the specific location where the data is hosted — either on the **LUMI** or **MareNostrum (MN5)** high-performance computing systems.

In the future, **Polytope** will support **federated access across databridges**, so users will no longer need to know the exact storage location.

:::{important}
**Current Polytope Server Addresses**

- **LUMI**  
  `polytope.lumi.apps.dte.destination-earth.eu`

- **MareNostrum (MN5)**  
  `polytope.mn5.apps.dte.destination-earth.eu`
:::

:::{note}
Climate Digital Twin (DT) data is distributed between LUMI and MN5 based on the specific simulation. You can find detailed information on the location of each dataset in the [dataset overview table](../2_digitial_twins_data_portfolio/2.1_dt_overview.ipynb#climate-dt-overview).
:::


## Example Using Earthkit-Data library

The from_source method from Earthkit-Data is used to extract data using a polytope source. Its method signature is documented [here](https://earthkit-data.readthedocs.io/en/latest/guide/sources.html#polytope)

```python
import earthkit.data

request = {
    'activity': 'ScenarioMIP',
    'class': 'd1',
    'dataset': 'climate-dt',
    'date': '20200102',
    'experiment': 'SSP3-7.0',
    'expver': '0001',
    'generation': '1',
    'levtype': 'sfc',
    'model': 'IFS-NEMO',
    'param': '134/165/166',
    'realization': '1',
    'resolution': 'standard',
    'stream': 'clte',
    'time': '0100',
    'type': 'fc'
}

data = earthkit.data.from_source(
    "polytope", # Source: The polytope source accesses the Polytope web services, using the polytope-client package.
    "destination-earth", # Collection: name of the polytope collection
    request,
    address="polytope.lumi.apps.dte.destination-earth.eu", # The address of the polytope service
    stream=False # if True, the data is read as a stream. Otherwise it is retrieved into a file and stored in the cache. Stream-based access only works for GRIB and CoverageJson data.
)
```

For more information on using polytope with earthkit data please refer to the earthkit data [polytope documentation section](https://earthkit-data.readthedocs.io/en/latest/guide/sources.html#polytope)


## Example Using Python Polytope Client:

```python
from polytope.api import Client

client = Client(
```
