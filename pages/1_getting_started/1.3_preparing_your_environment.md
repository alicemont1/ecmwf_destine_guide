## Preparing Your Environment

All necessary libraries to retrieve our data and run our services are available as Python packages installable via `pip` or `conda`.

A maintained `requirements.txt` and `environment.yml` file are available in the [`polytopes-examples`](https://github.com/destination-earth-digital-twins/polytope-examples) repository.



---

### Creating a Virtual Environment with `venv`

```bash
envname=destine

# Create a virtual environment
python3 -m venv $envname

# Activate it
source $envname/bin/activate      # macOS/Linux

# Install dependencies
pip install -r requirements.txt

# If using Jupyter notebooks, register your environment as a kernel for ipykernel
python3 -m ipykernel install --user --name=$envname

```


### Creating a Virtual Environment with `conda`

```bash
envname=destine
conda env create -n $envname -f environment.yml
conda activate $envname

# If using Jupyter notebooks, register your environment as a kernel for ipykernel
python3 -m ipykernel install --user --name=$envname

```
